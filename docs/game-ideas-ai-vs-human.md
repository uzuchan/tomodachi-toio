# ゲームアイデア集 — AI vs 人間（協力対戦）

> テーマ: 人数を1人/2人から選べる「AIチーム vs 人間チーム」。
> チーム内は必ず**協力**する。爆弾解除を要素のひとつに入れる。

## 共通フォーマット（全アイデアの土台）

- **2人モード** … 人間ペア（協力） vs AIキューブペア（協力）
- **1人モード** … 人間1人 ＋ **相棒AIキューブ1台**（協力） vs 敵AIキューブ
  - 1人のときだけAIが「敵」ではなく「友」として隣に来る。テーマ「友」の回収ポイント。
  - 相棒AIは"有能すぎない"のがコツ（たまに失敗して人間がフォロー → 絆が生まれる）
- **手持ち実機は2台（954 / h4i）**。足りないぶんは画面上の仮想キューブ（sim資産）で補完できる
  - 1人モード: 954=相棒（自走）、h4i=敵（自走）、人間はマウス/画面 or 954を手動 で成立 ✅
  - 2人モード: 954/h4i=人間の手ゴマ（位置センサー）、敵AIは仮想 or 借り実機
- 使える物理素材は A3簡易マット + レゴのみ（ハッカソン制約）

## 案1 🧨 ボム・バディーズ 〜爆弾かいじょ大作戦〜（本命）

**「Keep Talking and Nobody Explodes」のtoio版。** 爆弾解除がゲームの核。

- マット上の数マスが「爆弾モジュール」。制限時間内に全部解除したら勝ち。
- 役割分担が強制的に会話を生む:
  - **作業員** … マットのキューブを操作する。ただし解除手順は知らない
  - **マニュアル担当** … 画面の解除マニュアルだけ見える。マットは見ちゃダメ
- 解除操作はぜんぶ toio のセンサーで「物理化」する:
  | モジュール | 操作 | 使うセンサー |
  |---|---|---|
  | ダイヤル錠 | キューブをその場でゆっくり指定角度まで回す | position.angle |
  | ワイヤカット | 指定マスでダブルタップ | motion.doubleTap |
  | ニトロ運搬 | 傾け・振動厳禁でマスからマスへ運ぶ | posture / shake |
  | 起爆コード | 正しい順番でマスを踏む | position |
- **敵AIキューブ=ジャマー**が徘徊し、作業マスに近づくとコードを再シャッフル。
  すごろくで作った迂回走行ロジックを「人間を避ける」→「人間に絡む」に反転流用。
- **2人**: 人間A=作業員（954手動）、人間B=マニュアル。敵=h4i。
- **1人**: 人間=マニュアル担当、**相棒AI(954)が作業員として自走で実演**。
  人間が画面で指示 → 相棒が「りょうかい！」と動く。指示ミスも相棒は疑わない（信頼＝友）。敵=h4i。
- 実機2台で完全成立・爆弾解除ど真ん中・デモで会話が発生して映える。**推し。**

## 案2 🔍 24マスの爆弾しょり班（すごろく盤を流用）

**宝探し×ステルス。** 既存の24マス盤面・マス判定・自走コードをそのまま使える。

- 敵AIが24マスのどこかに爆弾を隠す。ヒントは分割情報（「行のヒント」と「列のヒント」）。
- **2人**: それぞれ違うヒントしか見えない（画面2分割 or スマホ）。口頭で照合して1マスに絞り、954を置いて解除ジェスチャー。
- **1人**: 相棒AIが**ガイガーカウンター役**。爆弾に近いほどLEDが赤く・ビープが速くなる。
  人間はそれを読んで指示。敵AIは盤面をパトロールし、視界（前方扇形）に入ると時間ペナルティ。
- 手数の少ない実装で「協力・爆弾・AI対戦」を全部満たす省エネ案。

## 案3 🏰 とりでディフェンス 〜レゴの城を守れ〜

**物理タワーディフェンス。** レゴ制約を武器に変える案。

- マット奥に人間チームの「城」（レゴ）。敵AIキューブが波状攻撃で城を目指す。
- 人間は**レゴの壁を手で置いて**進路を曲げる（敵AIは迂回ロジックで壁を回避しながら進む）。
- 敵は城のそばに**時限爆弾を設置**して撤退 → 人間は防衛と解除（現地でジェスチャー）の二正面作戦。
- **2人**: 壁担当と解除担当で分業。 **1人**: 相棒AIが体当たり（collision検知）で敵をノックバック。
- 「AIの経路探索 vs 人間の物理工作」という絵がわかりやすく、審査員に説明しやすい。

## 案4 🏃 はこびやリレー 〜さいごの30秒〜（テーマ回収エンド）

**前半は対戦、最後にどんでん返しで全員協力。**

- 解除キー（レゴパーツ）を**キューブの背中に載せて**対岸へ運ぶリレー対決。
  落とすと shake/posture で検知され振り出しへ。人間は手で運ぶが同じ振動制約を食らう。
- 両チームがキーを揃えても爆弾は止まらない——真の解除条件は
  **「人間もAIも全員、同時にボタンを押す」**。
- 敵だったAIキューブが近づいてきて「いっしょに、おして？」→ 全員同時押しでトゥルーエンド。
- 「AI vs 人間」で始めて「AIと人間の友情」で締める構成はテーマ「友」の回収として最強。
  単体ゲームにしてもいいし、**案1〜3の最終ステージ演出**として接ぎ木してもいい。

## 案5 🎭 スパイス: うらぎり/内通モジュール（どの案にも追加可）

- 2人モードの敵AIのうち1台が確率で**人間側に内通**（LEDの色でこっそり合図）。
- 1人モードの相棒AIがまれに**ウソのヒント**を言う（すぐ謝る）。信じるかどうかはあなた次第。
- 「AIを信頼できるか」という問いをゲームメカニクスにする。入れすぎ注意、隠し味程度に。

## 推しの組み合わせ

**案1（ボム・バディーズ）をコアに、案4のトゥルーエンドを最終ステージとして接続。**

理由:
1. 爆弾解除がルールの中心（要望ど真ん中）
2. 実機2台だけで1人/2人モード両方が成立（追加ハードなし）
3. マニュアル分離 → プレイ中に自然と会話が生まれ、デモ・審査で映える
4. 既存資産の再利用率が高い: 迂回走行（PR #2）→ジャマーAI、motion通知→解除ジェスチャー、
   TTS/ずんだもん→相棒のセリフ、sim→実機なしテスト

## 実装ステップ案（作るなら）

3. 敵ジャマーの徘徊（迂回ロジック反転）→ 1人モードの相棒自走 → モジュール追加の順に肉付け
4. 最後に案4のトゥルーエンド演出
